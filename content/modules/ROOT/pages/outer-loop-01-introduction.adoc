_1 MINUTE EXERCISE_

In this part of the workshop you will learn how to promote your application code from Development to Production.
You will work through the Developer *Outer Loop*: promote the CoolStore application to the different environments on OpenShift
using rich and advanced development services.

image::outer-loop.png[Developer Outer Loop,400,link=self,window=blank]

You will learn about:

* **Continuous Integration/Continuous Delivery** (CI/CD) with OpenShift Pipelines
* **GitOps** workflow with Argo CD

In addition, you will learn how to enable **Service Mesh** capability on OpenShift for monitoring your applications
and how to use it for advanced deployment techniques.

[NOTE]

====
